NOTHING DOT-MATRIX MAP

Roads are dots. Traffic is red / yellow / green. Navigation dims everything off-route.

01 / BROWSE — NO DIRECTION SET

Every road carries live traffic colour. Road class is dot size and spacing, not line weight. Route shields use the bundled Doto font.

02 / NAVIGATING — DIRECTION SET

Car is the red dot. Only the way ahead keeps RYG traffic; all background roads grey out. Shields off-route dim with the roads.

03 / INTERACTIVE — REAL MAP

Live OpenFreeMap vector tiles restyled into dot roads. Press BROWSE for RYG traffic on real roads, or PICK DESTINATION then click the map — OSRM draws a real route, the renderer greys the background and colours the way ahead.
